# Touchline til Android

Motor 12 driver de to offlinekarrierer, Spiller og Træner. Du kan installere TEST77 oven på den signerede TEST76.

Vælg **Kampdag → Spil selv**. I spillerkarrieren vælger du **Min spiller** eller **Hele holdet** før afspark. **Simulér kampen** giver begge hold til motoren. Tryk **KICK OFF** for at sætte bolden i spil. Brug **Kampmenu → Skift kamera** til at vælge Broadcast, Spiller / bold, Taktisk oversigt eller Målkamera.

Kildekode, aktiver, byggeværktøj og test ligger samlet i [Android-projektet](android-career/README.md).
