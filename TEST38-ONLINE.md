# Touchline TEST38 på Android

1. Åbn APK-filen på GitHub, mens du er logget ind på din GitHub-konto.
2. Brug downloadknappen på filsiden, og åbn den hentede APK.
3. Android kan bede om tilladelse til installation fra din browser. Tillad den for denne installation.
4. Vælg opdatering af **Touchline TEST**. Afinstallér ikke den tidligere testapp først.
5. Brug det eksisterende testlogin, og vælg grafikprofilen **Auto**.

Testappen har app-id `dk.touchline.footballidle.test` og erstatter ikke produktionsappen.
APK 37 og den oprindelige signeringsnøgle er ikke ændret.

Prøv login, menuer og én hel kamp. Kontrollér styring, boldkontakt, målreplay og gemning.
Telefonens FPS, varme og batteriforbrug er endnu ikke målt. Serverens automatiske kampkontrol
beviser ikke, at grafik eller touch føles flydende på OnePlus Nord 4.
