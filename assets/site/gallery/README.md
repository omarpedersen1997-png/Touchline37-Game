# Website screenshots

Four original JPEG screenshots supplied by the game owner for the website gallery on 11 November 2026. Files retain the supplied bytes, dimensions and compression. None contain EXIF metadata. These are actual app captures, distinct from the labelled SVG design illustrations elsewhere on the website.

Device status/navigation bars are clipped in the gallery layout using the dimensions in `src/site-gallery-data.js`. The full-length viewer displays the remaining app content in a scrollable frame. The three long scrolling captures have limited source resolution; they are not advertised as high-resolution store artwork.

Only these four versioned JPEG routes are publicly served. Other project/release files remain private. Website changes do not modify the approved Android APK or the Friday release schedule.
