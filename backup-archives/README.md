# Download af den komplette sikkerhedskopi

Repositoryets oprindelige kildefiler og authoringaktiver er bevaret direkte. Den komplette ZIP hedder `Touchline37-Game-Backup.zip`, er 247,867,032 bytes og har SHA256 `7aec050b2464c550bac5ada320506a54421780811101a40f57fb5a5b104411bd`. ZIP-filen omfatter også den verificerede oprindelige Git-historik med 67 commits.

ZIP-filen ligger under `backup-archives/Touchline37-Game-Backup.zip` og opbevares via Git LFS. På Android: log ind på GitHub i Chrome, åbn filen og vælg Download/Download raw file. Hent også .sha256-filen, hvis du vil kontrollere hash lokalt.

Filside: https://github.com/omarpedersen1997-png/Touchline37-Game/blob/main/backup-archives/Touchline37-Game-Backup.zip

Ved kloning med Git LFS installeret hentes den rigtige ZIP med `git lfs pull`. Hvis en ZIP-fil kun er ca. 130 bytes og starter med version https://git-lfs.github.com/spec/v1, er det kun pointeren; hent LFS-objektet først. GitHubs Code→Download ZIP kan afhænge af repositoryets LFS-arkivindstilling; brug derfor ZIP-filens downloadknap til den komplette historikbackup.

Uploaden er kontrolleret ved genhentning fra Git LFS til en tom lokal cache og fuld SHA256-sammenligning. Private signeringsnøgler, runtimehemmeligheder og produktionsdatabasedata er udeladt. Ingen hjemmeside- eller spilversion er publiceret. De tidligere backupkladder under Releases er ikke publicerede og er ikke downloadplaceringen.
